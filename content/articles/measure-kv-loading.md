## 背景与目标

这是一份实验写作示例，没有填入任何个人测量结果。目标是区分“选择更少 KV”与“更高效地读取相同 KV”带来的收益。

## 实验环境

至少记录模型、精度、GPU、CPU、SSD、有效读取带宽、软件版本与缓存设置。输入记录共享前缀长度、后缀长度、复用次数和请求顺序。

## 计时边界

```text
请求到达
  → 排队与前缀匹配
  → token 选择
  → SSD 读取
  → CPU 提取 / 重建
  → H2D
  → attention 计算
  → 首 token 输出
```

异步执行时，各阶段耗时不能直接相加成端到端延迟，需要结合执行时间线看依赖和重叠。

## 基线与消融

1. 全量重计算：判断存储复用是否值得。
2. 全量 KV 读取：观察稀疏选择收益。
3. 固定相同选中集合：隔离 I/O 策略收益。
4. 单独启用布局、合并与维护：判断每个机制的作用。
